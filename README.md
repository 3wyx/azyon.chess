# Шахматы в браузере

Шахматы для двух игроков на одном экране или против бота. Работает в браузере, на компьютере и на телефоне, без установки. Весь код в одном файле `index.html`.

**Играть:** https://3wyx.github.io/azyon.chess/

## Что есть в игре

**Обязательное**
- Все фигуры ходят по правилам, включая рокировку, взятие на проходе и превращение пешки.
- Определяются шах, мат и пат. Также ничья при недостатке материала, троекратном повторении позиции и 50 ходах без взятий и ходов пешками.
- Два игрока на одном устройстве, видно, чей сейчас ход, есть кнопка «Заново».

**Плюсы**
- Игра против бота трёх уровней, можно выбрать цвет.
- Подсветка возможных ходов, история ходов, отмена хода.
- Шахматные часы (3, 5 или 10 минут).
- Адаптивная вёрстка для телефона.

## Своя фишка: режимы, которых нет в обычных шахматах

Режимы включаются на начальной странице.

- **Способности** (по одной за партию на игрока, используются до хода):
  ❄ Заморозка: фигура соперника не может ходить два его хода, но продолжает бить.
  🛡 Щит: фигура переживает первое взятие, щит сгорает.
  ✚ Воскрешение: возвращает свою съеденную фигуру на свободную стартовую клетку.
- **Падающие клетки:** раз в несколько ходов пустая клетка в центре доски падает и становится стеной. Пешка может перепрыгнуть упавшую клетку.
- **Туман войны:** видно только то, что видят ваши фигуры. В игре вдвоём между ходами появляется экран передачи устройства.

## Как запустить локально

Скачайте `index.html` и откройте его в браузере. Больше ничего не нужно (шрифты подгружаются из Google Fonts, без них страница тоже работает).
